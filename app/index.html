Local model — Muse Glimmer

Deep synthesis runs on Muse Glimmer served on this device (Ollama, llama.cpp, or vLLM). The app only ever calls the endpoint below on this machine — no data leaves this device. If the server is off, templated local drafts are used instead.

Set up deep synthesis

Deep synthesis needs the free Ollama app and the Muse Glimmer model running on this device. Once set up, it starts with your computer — there is nothing to redo.

  1. Install Ollama from ollama.com and open it once.
  2. Copy the commands below, paste them into Terminal (macOS) or Command Prompt (Windows), and press Enter. The first line downloads the model (about 17–20 GB, once only).
  3. Come back here and choose Check connection.
ollama pull muse-glimmer
OLLAMA_ORIGINS=http://localhost:5173 ollama serve

Keep the Terminal window open while you use deep synthesis. Your entries are only ever sent to this device — the commands above let this app talk to the model on your own machine.
